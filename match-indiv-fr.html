Le Principe : Match Play individuel. Chaque joueur joue pour lui-même.

Le Score (Match) : 1 point est en jeu à chaque trou. Le joueur réalisant le meilleur score remporte le point.

Égalité (Skins) : Si le meilleur score est partagé par plusieurs joueurs, l'option "Report des points" détermine la suite :
- Oui : Le point s'ajoute à la cagnotte du trou suivant (ex: le trou suivant vaudra 2 points).
- Non : Le point du trou est annulé (partagé).

La Croix (X) en Brut : Ramasser la balle. Vaut Par + 4.

En mode Net, les calculs de scores détaillés s'appliquent :

Score Brut Ajusté (SBA) : Le SBA correspond au score brut, mais plafonné pour éviter qu'un très mauvais trou ne pénalise trop le résultat global. Le maximum par trou est défini par : Par du Trou + Coups Reçus sur ce Trou + 2. Si vous ramassez la balle (Croix), le score brut est considéré comme Par + 4, puis plafonné par ce maximum. Le SBA final est la somme de ces scores ajustés.

Index Joué (IND) : Le score différentiel reflète votre performance réelle du jour par rapport à la difficulté du parcours. Il est calculé ainsi : (113 / Slope) x (SBA – SSS).

Score Stableford (STB) : Convertit votre score net par trou en points (2 pts pour le Par net, 3 pour le Birdie net, etc.).
