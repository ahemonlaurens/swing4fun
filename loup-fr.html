Règles du Loup ▶ Afficher

Le jeu se joue à 4. À chaque trou, un joueur différent est désigné "Loup".

Le Loup choisit un partenaire (2v2) ou affronte les 3 autres (1v3). On compare le meilleur score (Net ou Brut) de chaque camp pour déterminer le vainqueur.

  • 2 contre 2 : Les gagnants marquent +1 pt, les perdants -1 pt.
  • Loup Solitaire (x2) : S'il gagne : +6 pts (autres -2). S'il perd : -6 pts (autres +2).
  • Loup d'Or (x3) : Annoncé avant le 1er drive. Gain: +9/-9, autres -3/+3.
  • Carry Over : En cas d'égalité parfaite, les points sont reportés au trou suivant.

La Croix (X) : Entrer "X" signifie ramasser la balle. En mode Brut, cela vaut Par + 4. En mode Net, cela limite le score à Par + Coups Reçus + 2. Ce score s'additionne à votre total.
